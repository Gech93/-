# 互补数字人 - 小程序

一个与使用者人格互补的AI数字人应用，帮助用户在决策犹豫时获得不同视角的参考。

## 🎯 核心功能

- **🧠 MBTI人格测试**：通过MBTI问卷发现你的性格特点
- **🤖 互补人格**：生成与你人格互补的AI数字人
- **💬 智能对话**：与数字人进行自然的文字对话
- **🎯 决策辅助**：在重要决策时提供多角度分析
- **📈 持续成长**：数字人随着使用不断学习和进化

## ✨ 特色功能

### 多人格支持
- 最多可创建5个不同的数字人
- 适用于不同场景（工作、情感、创意等）
- 每个人格独立管理，互不影响

### 互补度调节
- 0-100%可调的互补程度
- 每月限修改1次，保护人格一致性
- 从人格创建时开始计时

### 决策模式
- 结构化的分析框架
- 主动提问关键问题
- 明确区分用户倾向和互补视角

### 成长系统
- 被动成长：对话历史自动分析
- 主动成长：用户标记好的回答
- 时间衰减：近期对话权重更高

## 🛠️ 技术栈

- **框架**：uni-app + Vue 3
- **语言**：TypeScript
- **状态管理**：Pinia
- **样式**：SCSS
- **AI**：模拟AI（可后期接入文心一言/GPT-4）

## 🚀 快速开始

### 1. 安装依赖

```bash
npm install
```

### 2. 运行开发服务器

```bash
# H5版本
npm run dev:h5

# 微信小程序
npm run dev:mp-weixin
```

### 3. 在微信开发者工具中导入

1. 打开微信开发者工具
2. 导入项目，选择 `uniapp-app` 目录
3. 填写 AppID（可在 manifest.json 中修改）
4. 点击确认，等待编译完成

## 📋 使用说明

### 首次使用

1. 打开应用，完成MBTI人格测试
2. 根据测试结果，系统会生成你的互补数字人
3. 给你的数字人起个名字
4. 设置初始互补度（可随时调节）
5. 开始与数字人对话！

### 日常使用

- **切换人格**：在人格列表页面，点击不同的人格卡片
- **调节互补度**：在聊天页面底部，拖动滑动条
- **开启决策模式**：点击"决策"按钮，开启结构化分析
- **管理隐私**：在设置页面，调整数据存储方式

## 🔧 配置说明

### 修改AppID

在 `manifest.json` 中修改：

```json
{
  "mp-weixin": {
    "appid": "你的AppID"
  }
}
```

### 接入真实AI

当前版本使用模拟AI回复。如需接入真实AI（如文心一言），请修改 `stores/conversation.ts` 中的 `sendMessage` 函数。
