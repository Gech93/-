# 华为备忘录 → Vivo 转移工具

轻松将您的华为备忘录数据转换并转移到vivo手机的工具。

## 📋 功能特性

- 支持多种输入格式：TXT、CSV、JSON
- 提供网页版和Python脚本两种使用方式
- 导出为vivo兼容的TXT、CSV格式
- 支持批量处理多个文件
- 简洁美观的用户界面

## 🚀 使用方法

### 方法一：网页版（推荐，无需安装）

1. 在浏览器中打开 `memo-transfer.html`
2. 按照界面上的步骤操作：
   - 从华为手机导出备忘录
   - 上传文件到网页
   - 预览数据
   - 下载转换后的文件
   - 导入到vivo手机

### 方法二：Python脚本（适合技术用户）

1. 确保已安装 Python 3.6+
2. 运行脚本：
   ```bash
   python memo_transfer.py 备忘录文件.txt
   # 或者处理整个文件夹
   python memo_transfer.py ./huawei_memos/
   # 指定输出目录
   python memo_transfer.py input.txt -o ./my_output
   ```

## 📱 详细使用步骤

### 第一步：从华为手机导出备忘录

**方式A：直接在手机上导出**
1. 打开华为备忘录应用
2. 点击右上角菜单（三个点）→ 设置
3. 选择"导入/导出" → "导出为TXT"
4. 选择要导出的备忘录，保存到手机存储

**方式B：通过华为云空间**
1. 确保备忘录已开启云同步
2. 在电脑浏览器访问 cloud.huawei.com
3. 登录华为账号，进入备忘录
4. 选择要导出的备忘录，点击导出

### 第二步：使用工具转换

选择网页版或Python脚本进行转换。

### 第三步：导入到vivo手机

1. 将转换后的文件（TXT或CSV）传输到vivo手机
2. 打开vivo"原子笔记"或备忘录应用
3. 点击菜单 → 设置 → 导入数据
4. 选择刚才传输的文件完成导入

## 📁 文件说明

- `memo-transfer.html` - 网页版工具，直接在浏览器使用
- `memo_transfer.py` - Python脚本版，适合批量处理
- `example/` - 示例文件目录
- `output/` - 转换后的文件输出目录

## 💡 提示

- vivo原子笔记通常对TXT和CSV格式支持最好
- 如果直接导入有问题，可以尝试使用第三方笔记应用（如印象笔记、有道云笔记）作为中间桥梁
- 建议先转换少量备忘录测试，确认没问题后再批量转换
