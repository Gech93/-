# 互补数字人 使用指南

一个基于 MBTI / 大五人格的前端测评与AI对话应用，为你的性格生成"互补人格"，并提供带有记忆机制的 AI 陪伴对话。

## 技术栈

- **前端框架**：Vue 3 + TypeScript
- **跨平台框架**：uni-app（同时输出微信小程序与 H5）
- **状态管理**：自定义响应式 Store（src/stores/persona.ts）
- **AI 服务**：DeepSeek API（直连，或经 uniCloud 云端网关代理）
- **云端能力**：uniCloud 云函数（chat-gateway，服务端持有 API Key）

## 功能概览

- **MBTI 测评（16题）与大五人格测评（25题）**
- **互补人格生成**：根据互补度翻转维度，配合大五约束，生成"互补但可理解"的人格
- **多会话聊天**：每个人格可建立多个会话，支持新建 / 切换 / 删除，旧数据自动迁移
- **记忆机制**：
  - 对话事实抽取（用户偏好、身份、计划等），按"半衰期"随时间衰减，久未回顾渐渐遗忘
  - 滚动摘要 + 行为画像（情绪倾向 / 决策风格 / 表达风格 / 深层需求）
  - AI 驱动记忆更新（DeepSeek 结构化输出 memoryUpdates），离线时回退规则抽取
- **反馈记忆化**：对 AI 回复的"有用 / 没帮助"反馈会被记忆，并按半衰期衰减
- **数据管理**：导出 / 导入 JSON 备份、清空全部对话、清除所有数据
- **AI 服务配置**：支持直连 DeepSeek（客户端填写 API Key）或启用云端网关（Key 存放于服务端环境变量）

## 使用步骤（小程序 / H5）

### 1. 安装依赖并编译

```bash
cd complement-digital-human-mp
npm install
# 微信小程序
npm run build:mp-weixin
# H5
npm run build:h5
```

编译输出：
- 微信小程序：`dist/build/mp-weixin/`
- H5：`dist/build/h5/`

### 2. 导入微信开发者工具

1. 打开微信开发者工具 → 导入项目
2. 选择编译输出目录 `dist/build/mp-weixin`
3. AppID 使用测试号（`__UNI__WEIXIN`）或你自己的小程序 AppID 均可

### 3. 配置 AI 服务（可选）

在「设置 → AI 服务」中：

- **方式一：客户端直连**：在对话页的设置弹窗填入 DeepSeek API Key
- **方式二：云端网关（推荐）**：
  1. 在 uniCloud 控制台（阿里云服务空间）创建并部署云函数 `uniCloud-aliyun/cloudfunctions/chat-gateway`
  2. 为云函数配置环境变量 `DEEPSEEK_API_KEY`
  3. 将云函数 URL 填入「网关地址」，并打开「使用云端网关」开关

启用网关后，AI 请求经你的云函数转发，API Key 不再暴露在客户端；网关不可用时自动回退直连 / 离线模式。

### 4. 数据备份

「设置 → 数据管理」支持：
- **导出数据备份**：H5 直接下载 `.json` 文件；小程序端将备份文本复制到剪贴板，粘贴保存即可
- **导入数据备份**：H5 选择本地文件；小程序端通过"从聊天中选择文件"导入，导入前请确认会覆盖当前全部数据
- **清空全部对话**：仅删除对话记录，保留人格与记忆
- **清除所有数据**：完整重置应用

## 页面结构

```
src/
├── pages/
│   ├── index/               # 首页
│   ├── mbti-test/           # MBTI 与 大五测评
│   ├── persona-list/        # 人格列表
│   ├── persona-create/      # 创建人格
│   ├── persona-profile/     # 互补人格档案（记忆 / 反馈展示）
│   ├── chat-list/           # 会话列表
│   ├── chat-conversation/   # 聊天对话（记忆写入 / AI 调用）
│   └── settings/            # 设置（AI 服务 / 数据管理）
├── stores/persona.ts        # 全局状态与记忆衰减逻辑
├── utils/chatSessions.ts    # 多会话存储与迁移
├── utils/backup.ts          # 备份导出 / 导入 / 清空会话
└── manifest.json            # 版本号（versionName）等应用配置
```

## 关键设计说明

- **版本号**：设置在「设置」页展示的版本号直接读取 `src/manifest.json` 的 `versionName`，改版时只需修改 manifest
- **记忆衰减**：反馈记忆半衰期 7 天、事实记忆半衰期 30 天，强度低于遗忘阈值后自动清除，避免记忆无限膨胀
- **多会话键**：`chat_sessions_<personaId>` 存会话元数据，`chat_messages_<personaId>_<sessionId>` 存消息，旧版本单会话数据启动时自动迁移
- **数据安全**：API Key 不参与备份导出，备份文件中仅包含用户数据与网关开关配置

## 常见问题

**Q: 为什么小程序聊天没有 AI 回复？**
A: 检查「设置 → AI 服务」是否已启用云端网关或已填入 API Key；未配置时会使用内置的离线模拟回复。

**Q: 如何确认导入了正确的目录？**
A: 检查目录中是否有 `app.js`、`app.json`、`pages/` 文件夹等文件。

**Q: 换手机后如何保留数据？**
A: 旧设备「设置 → 导出数据备份」，新设备「导入数据备份」即可整体迁移。
