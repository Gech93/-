
# 互补数字人 - 产品需求文档(PRD)

## 1. Product Overview
一个能与使用者人格互补的AI数字人应用，通过MBTI和人格蒸馏技术构建，帮助用户在决策犹豫时获得不同视角的参考。
- 解决用户决策时的思维盲区问题，提供客观、互补的外部视角；目标用户为需要外部参考的各类人群
- 市场价值在于填补个性化AI陪伴与决策辅助的空白，满足用户对"另一个自己"的需求

## 2. Core Features

### 2.1 User Roles
| Role | Registration Method | Core Permissions |
|------|---------------------|------------------|
| 普通用户 | 手机号/微信注册 | 完整使用所有功能，管理个人数据 |

### 2.2 Feature Module
1. **欢迎/引导页**：产品介绍、MBTI测试入口
2. **MBTI测试页**：人格问卷、结果展示
3. **聊天首页**：对话列表、数字人信息
4. **对话页**：实时聊天、互补度调节
5. **设置页**：隐私设置、人格档案管理、多平台同步

## 3. Core Process
用户首次使用时，完成MBTI测试建立初始人格档案，系统生成互补数字人。日常使用中，用户可以与数字人聊天，数字人会从对话中持续学习用户人格，用户可调节互补程度。遇到决策问题时，可使用决策模式获得多角度建议。

```mermaid
graph TD
    A[首次登录] --&gt; B[MBTI测试]
    B --&gt; C[生成互补数字人]
    C --&gt; D[日常聊天]
    D --&gt; E{需要决策参考?}
    E --&gt;|是| F[决策模式]
    E --&gt;|否| D
    D --&gt; G[数字人持续学习]
    G --&gt; H[人格档案更新]
    H --&gt; D
    I[设置] --&gt; J[隐私管理]
    I --&gt; K[互补度调节]
    K --&gt; D
```

## 4. User Interface Design
### 4.1 Design Style
- **主色调**：深蓝色(#1E40AF)代表理性思考，淡紫色(#8B5CF6)代表互补思维
- **辅助色**：温暖橙色(#F97316)用于强调按钮
- **按钮风格**：圆角矩形，轻微阴影，点击时有缩放反馈
- **字体**：Inter/Noto Sans，正文16px，标题20-24px
- **布局风格**：卡片式布局，清晰的信息层级
- **图标风格**：线性图标，简洁现代

### 4.2 Page Design Overview
| Page Name | Module Name | UI Elements |
|-----------|-------------|-------------|
| 欢迎/引导页 | 产品介绍 | 渐变背景，卡片式布局，动画效果展示数字人概念 |
| MBTI测试页 | 问卷模块 | 干净的白色背景，题目居中，进度条在顶部 |
| 聊天首页 | 对话列表 | 列表项带头像预览，底部悬浮新建按钮 |
| 对话页 | 聊天界面 | 用户消息在右(蓝色)，数字人在左(紫色)，互补度调节器在侧边 |
| 设置页 | 人格档案 | 可视化雷达图展示人格维度，滑动条调节互补度 |

### 4.3 Responsiveness
- **移动端优先**，自适应小程序环境
- **触摸优化**：按钮最小44x44px，适合手指点击
- **横竖屏适配**：关键页面支持两种方向

### 4.4 3D Scene Guidance (未来版本)
- **环境**：简约的虚拟空间，柔和的HDRI光照
- **光照**：三点布光，营造温暖但专业的氛围
- **相机**：第三人称视角，可轻微旋转观察数字人
- **交互**：点击数字人触发打招呼动画
- **后处理**：轻微 bloom 效果，增强科技感
