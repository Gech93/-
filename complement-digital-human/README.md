# 互补数字人 - 小程序/Web应用

一个与你人格互补的AI伙伴，帮助你在决策犹豫时获得不同视角。

## 🌟 功能特性

### 核心功能
- **🧠 MBTI人格测试** - 发现你的性格特点
- **🤖 互补人格** - 生成与你互补的AI人格
- **💬 智能对话** - 与数字人自然交流
- **🎯 决策模式** - 重要决策时的结构化分析
- **📈 持续成长** - 从对话中学习和进化

### 高级功能
- **多人格支持** - 最多创建5个人格，适用于不同场景
- **互补度调节** - 0-100%可调，每月限修改一次
- **隐私保护** - 多种数据存储模式可选
- **本地存储** - 数据保存在你的设备上

## 🚀 快速开始

### Web版本（当前运行）
项目已启动，在浏览器中访问:
```
http://localhost:5173/
```

### 小程序版本
1. 打开 **微信开发者工具**
2. 点击"导入项目"
3. 选择 `uniapp-app` 目录（或项目目录）
4. 填写AppID（可以使用测试号）
5. 点击确定

## 📱 使用流程

### 1. 开始测试
- 进入首页，点击"开始体验"
- 完成MBTI人格测试（6道题）
- 查看你的人格类型

### 2. 创建数字人
- 选择角色类型（分析师/倾听者/创意伙伴等）
- 为你的数字人取名
- 设置初始互补度

### 3. 开始对话
- 进入聊天界面
- 与你的互补数字人交流
- 切换到决策模式获得更深入分析

### 4. 管理设置
- 在设置中调整隐私选项
- 切换不同的人格
- 查看和管理对话历史

## 🛠️ 技术栈

- **框架**: Vue 3 + Vite
- **状态管理**: Pinia
- **路由**: Vue Router
- **样式**: 原生CSS + 渐变设计
- **存储**: LocalStorage
- **AI**: 模拟版本（可接入真实AI）

## 📄 设计理念

### 产品定位
- **互补而非模仿** - 提供不同视角，不是重复用户的想法
- **辅助而非替代** - 帮助思考，不替用户做决定
- **客观而非迎合** - 保持真实性，不刻意讨好

### 人格设计
- **互补算法** - 与用户MBTI类型相反
- **成长系统** - 从对话中学习用户偏好
- **个性化** - 用户可自定义角色类型

### 用户体验
- **简洁直观** - 三步即可开始使用
- **响应式设计** - 适配移动设备
- **流畅动画** - 提升使用愉悦感
