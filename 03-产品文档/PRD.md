# 互补数字人 - 产品需求文档(PRD)

## 1. 产品概述

一个能与使用者人格互补的AI数字人应用，通过MBTI和人格蒸馏技术构建，帮助用户在决策犹豫时获得不同视角的参考。

**核心价值**：
- 解决用户决策时的思维盲区问题，提供客观、互补的外部视角
- 支持多个人格档案，满足不同场景需求（工作、情感、创意等）
- 数字人随用户成长而进化，保持人格一致性同时不断学习

**目标用户**：需要外部参考的各类人群，特别是面临重要决策、寻求不同视角的用户

## 2. 核心功能

### 2.1 用户角色

| Role | Registration Method | Core Permissions |
|------|---------------------|------------------|
| 普通用户 | 手机号/微信注册 | 完整使用所有功能，管理个人数据和人格档案 |

### 2.2 功能模块

#### 2.2.1 欢迎/引导页
- 产品介绍和核心价值展示
- 首次登录引导（MBTI测试或人格选择）
- 展示用户已有的人格档案列表

#### 2.2.2 MBTI测试页
- 标准化MBTI人格问卷（简化版6-12题）
- 支持中途保存进度
- 结果展示与人格档案生成

#### 2.2.3 人格档案管理页
- **多人格支持**：最多5个人格档案同时存在
- **人格命名**：用户自定义名称，系统提供建议名称（分析师、倾听者、创意伙伴、规划师、探险家）
- **人格选择**：用户选择当前使用的人格
- **互补度调节**：0-100%可调
- **修改限制**：每月一次免费重置机会（从人格创建时开始计时）

#### 2.2.4 聊天页
- 实时文字对话
- **互补度调节器**：滑动条调节互补程度(0-100%)
- **决策模式**：专门的决策咨询模式
  - 在开启按钮旁添加"?"图标，点击显示决策模式说明
  - 决策模式说明内容：
    - **目的**：帮助分析重要决策，提供多角度视角
    - **特点**：更结构化的分析框架，会主动提问关键问题
    - **适用场景**：职业选择、人生重大决定、重要人际问题
- **主动学习功能**：
  - 用户可标记"这个回答更好"
  - 标记的回答具有更高权重

#### 2.2.5 设置页
- **隐私设置**：用户自行选择数据存储模式
- **人格档案管理**：查看/编辑/重置人格
- **数据管理**：导出/删除个人数据

## 3. 核心流程

### 3.1 用户首次使用流程

```
用户首次登录 
  ↓
完成MBTI测试 
  ↓
创建第一个互补数字人（用户命名）
  ↓
设置初始互补度 
  ↓
开始日常使用
```

### 3.2 多人格管理流程

```
用户选择"创建新人格" 
  ↓
选择已有MBTI档案或重新测试
  ↓
系统提供人格建议（如：分析师、倾听者、创意伙伴）
  ↓
用户自定义命名 
  ↓
设置新人格的互补度 
  ↓
新人格创建成功（从此时开始计算每月修改冷却）
```

### 3.3 日常使用流程

```
选择所需的人格档案 
  ↓
进入聊天界面 
  ↓
选择模式：普通对话 / 决策模式 
  ↓
进行对话 
  ↓
数字人被动学习（对话历史自动分析） 
  ↓
数字人主动学习（用户标记好的回答） 
  ↓
定期更新人格档案
```

### 3.4 互补度调节流程

```
用户调整互补度 
  ↓
系统检查修改冷却时间 
  ↓
如果未到修改时间 
  ↓
显示距离下次可修改的剩余时间 
  ↓
如果已到修改时间 
  ↓
允许修改并更新冷却时间 
  ↓
每月提供一次免费重置机会（独立于互补度调节）
```

## 4. 用户界面设计

- **主色调**：深蓝色(#1E40AF)代表理性思考，淡紫色(#8B5CF6)代表互补思维

## 5. 数字人成长系统

### 5.1 被动成长

- **对话历史分析**：系统自动分析用户对话内容
- **时间衰减权重**：
  - 近期对话权重更高
  - 越久远的对话比重越低
  - 具体衰减曲线可配置（如指数衰减或线性衰减）

### 5.2 主动成长

- **用户标记机制**：
  - 用户可标记"这个回答更好"
  - 被标记的回答权重显著高于未标记的
  - 标记数据直接影响人格学习
- **反馈循环**：好的回答会强化相应的人格特征

### 5.3 成长限制

- **人格稳定性保护**：
  - 重大变化需要多次确认
  - 避免过度迎合用户短期偏好
- **一致性维护**：保持人格核心特征不变

## 6. 客观性原则

### 6.1 事实判断

- **客观事实优先**：
  - 当用户陈述与客观事实不符时，数字人不会盲目认同
  - 会温和地提供正确信息和依据
- **证据展示**：提供信息来源和推理过程

### 6.2 主观问题处理

- **无准确答案的对话**：
  - 数字人自主判断应提取的经验
  - 结合用户人格特征给出建议
  - 不强加价值观，保持中立
- **开放性讨论**：对于开放式问题，提供多个视角

### 6.3 决策建议

- **不替代决策**：
  - 提供信息和视角
  - 帮助用户理清思路
  - 最终决策权在用户
- **风险提示**：在重大决策时主动提示风险因素

## 7. 隐私与数据存储

### 7.1 存储模式选择

用户可自行选择存储模式：

| Storage Mode | Description | Data Security |
|-------------|-------------|---------------|
| 本地存储 | 数据仅保存在用户设备 | 高（数据不出设备） |
| 云端加密存储 | 数据加密后保存在服务器 | 中（加密保护） |
| 混合模式 | 基础数据本地，偏好设置云端 | 中高 |

### 7.2 数据管理

- **数据导出**：支持导出个人数据和对话历史
- **数据删除**：一键删除所有个人数据
- **数据迁移**：支持更换设备时数据迁移

## 8. 技术架构

### 8.1 优先平台

**优先难度低的方案**，后续再具体延申补充：

- **第一阶段**：微信小程序 / Web网页版
  - 开发难度低
  - 便于快速验证产品概念
  - 用户获取成本低
- **第二阶段**：独立App（iOS/Android）
  - 更好的用户体验
  - 更多系统能力
- **第三阶段**：多平台统一

### 8.2 AI能力

- **完全依赖AI**：目前阶段不引入真人审核或人工干预
- **AI模型选择**：根据平台和成本选择合适的模型
- **对话生成**：支持流式输出，提升响应体验

- 语音对话（可选）
- API开放（可选）
